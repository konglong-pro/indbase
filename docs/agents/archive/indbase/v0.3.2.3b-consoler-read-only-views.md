## Objective

Add bounded, current-state, read-only consoler artifact views for:

```text
document
review item
task
error
doctor report
```

Success means dogfood users can inspect the Source Trust Loop without consoler reading vault files or DB state directly.

## Scope

Implement only read-only view expansion:

- strict `indbase://...` artifact URI parsing
- fixed budgets and truncation metadata
- view envelope fields: `view_semantics`, `limits`, `truncated`
- artifact blocks for focused show commands, source search, and doctor
- no artifact blocks from list commands
- stable artifact view error codes
- focused tests and a v0.3.2.3b release gate

Do not implement:

- Web UI, full TUI, vault browser, file browser, arbitrary URI fetch, title/path lookup, or fuzzy lookup
- review/category/tag mutation, `review_resolve`, or doctor repair
- `ask`, retrieval packages, embeddings, generated answers, semantic search, or reranking
- transition/translation/output artifact gallery
- full document revision browser
- consoler protocol schema, runtime, store, replay, or renderer changes from this repo

## Do Not Touch

- Do not import `consoler_agent_sdk` from `indbase_core`.
- Do not shell out to `indb` from `indbase_agent`.
- Do not add new consoler protocol fields or runtime behavior from indbase.
- Do not commit local consoler SDK paths, smoke vaults, private vault content, or unsanitized dogfood snippets.
- Do not add a doctor run table or repair path.
- Do not make list commands emit row-level artifact spam.
- Do not turn `metadata.vault_path` or `artifact_uri` into title/path lookup.
- Do not break existing v0.3.2.3a document search artifact behavior.

## Steps

1. Refactor `artifact_view.py` around strict URI parsing, fixed limits, view envelopes, and stable error codes.
2. Upgrade document views to 4000 chars of source preview and at most 10 current chunks/snippets.
3. Add review item, task, error, and doctor report view builders.
4. Add artifact blocks to `doc_show`, `review_show`, `task_show`, `error_show`, and `doctor`; keep list commands artifact-free.
5. Keep `search_sources` document artifacts bounded to five and carrying `metadata.vault_path`.
6. Ensure all artifact views contain only non-artifact render blocks.
7. Add focused read-only view contract tests.
8. Add the v0.3.2.3b release gate.
9. Update `docs/testing.md` and `docs/project-status.md` after implementation.

## Done Means

- `indbase.document`, `indbase.review_item`, `indbase.task`, `indbase.error`, and `indbase.doctor_report` views work.
- Unsupported and malformed URIs fail with stable explicit error codes.
- Every view is bounded and reports `view_semantics`, `limits`, and `truncated`.
- Doctor report view is ephemeral, read-only, and does not write DB state.
- List/show/search/doctor artifact emission follows the planning doc.
- Artifact view blocks are not nested.
- `indbase_core` has no consoler SDK import.
- v0.3.2.3a and v0.3.2.3b gates pass.
- Tag/search regressions and compileall pass.
- Local consoler smoke passes or skips for an explicit environment reason.
