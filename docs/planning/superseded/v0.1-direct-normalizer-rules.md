# v0.1 Direct Normalizer Rules

The historical v0.1 direct normalizer / MarkItDown production conversion rules
are superseded by v0.2 swallow-backed ingest.

Current rule:

- swallow owns production conversion.
- indbase owns trust, identity, promotion, vault state, revisions, chunks,
  indexes, tasks, errors, reviews, artifacts, and doctor.
- `features.swallow_ingest=false` fails visibly with
  `legacy_conversion_retired`.
- Production ingest must not fall back to direct normalizers or MarkItDown.
