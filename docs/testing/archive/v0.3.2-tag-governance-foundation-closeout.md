# v0.3.2 Tag Governance Closeout

## Outcome

Shipped Formal Tags, Candidate Tags, resolution, admission policy, volume budget, feedback audit data, and relation-backed tag filters.

## Frozen Rules

- Automatic workflows must not create Formal Tags directly.
- Raw/candidate tags are not trusted filter sources.
- Manual tags are not silently replaced by automatic workflows.
